# Learning and experiments v0.1

Status: proposed guidance. [Experiment charter](../templates/experiment-charter.md)

## Frame a useful question

Write: “For [population and context], changing [specific mechanism] should improve [outcome] compared with [baseline], while preserving [constraints].” Record alternative explanations and what would disconfirm the claim. Decide what the answer will change before investing in measurement.

Prefer one interpretable change at a time for the first pilot. If several elements must change together, name the bundle and limit any attribution to that bundle. A failed comparison can still identify a useful next question.

## Choose a proportionate comparison

| Method | Useful for | Main caution |
|---|---|---|
| Fixed offline replay | Comparing pinned configurations on the same case set | Cases may not represent current work; tuning can contaminate them |
| Shadow operation | Observing a candidate without granting it external effects | Shadow inputs and available context may differ from live work |
| Paired or randomized comparison | Investigating causal effects when feasible | Assignment, interference, sample adequacy, and participant conditions need care |
| Before/after observation | Small operational improvements when stronger designs are impractical | Seasonality, case mix, other changes, and practice effects weaken attribution |
| Qualitative inquiry | Understanding experience, failure mechanisms, and new hypotheses | Sampling and interpretation need visibility; testimony does not establish every claim |

These are proposed choices, not universal methodological endorsements. Document why the chosen method is adequate for the actual decision. Obtain domain expertise when a causal or high-consequence claim needs it.

## Plan before looking at results

Pin the case-set revision, eligibility rules, assignment, model/configuration, metric definitions, evaluator, acceptance thresholds, regression limits, missing-data rules, duration, stopping rules, and sufficient-evidence basis. Keep tuning cases separate from final assessment cases. Repeated searching for a passing candidate requires a disclosed analysis plan and a fresh or otherwise appropriate confirmation set.

No universal minimum sample size is supplied by this framework. The pilot's count threshold is a synthetic completeness guard, not a power calculation. Real studies need an adequacy rule appropriate to expected variability, effect size, claim, and consequence.

## Bound the experiment

Specify permitted actions, data, tools, targets, resource ceilings, expiration, affected people, consent/notice, exclusions, stop conditions, responders, and supported recovery. Test containment before granting external effects. An offline result does not authorize production exposure.

Keep the learning record concise. A useful failed hypothesis, an unresolved question, and a supported improvement are all valid outputs when their evidence and decision implications are clear.
