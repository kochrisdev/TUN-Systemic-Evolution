# Documentation

## Choose a reading path

**For a team:** start with the [introduction](INTRODUCTION.md), run a [first learning cycle](FIRST-LEARNING-CYCLE.md), and adapt the [fictional support example](../examples/human-ai-support-evolution.md).

**For an implementer:** read [scope](SCOPE.md), run the [standalone pilot](PILOT.md), then explore the [family pilot](FAMILY-PILOT.md) and its explicit adapters.

**For a reviewer:** read the [draft specification](SPECIFICATION-v0.1.md), [threat model](THREAT-MODEL.md), [assessment matrix](CONFORMANCE-MATRIX.md), and named validation records. Draft obligations are broader than the demonstrated code.
