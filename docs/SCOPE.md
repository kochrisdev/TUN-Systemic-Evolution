# Scope and non-claims

Updated: 2 October 2026. [Status](STATUS-AND-ROADMAP.md)

## Available

A proposed discipline, concept note, manifesto, twelve requirements, general record vocabulary, human development guidance, operating guides, companion mappings pinned to reviewed commits, four templates, a fictional example, an experimental schema document, and a Python/SQLite reference pilot with local tests.

The pilot records immutable configurations and experiments through its API, synthetic observations, evidence assessments, owner-fixture decisions, local activation, monitoring, and restoration. It checks bindings, metric thresholds, simple completeness/freshness, scope, current policy, concurrent state changes, and restart persistence. The journal is not independently tamper-proof.

## Not implemented or established

No model inference, online learning, model training, autonomous experiment execution, real metric collection, participant study, statistical causal analysis, production deployment, remote recovery, authentication, tenant separation, retention/deletion service, public website, stable SDK, or actual companion interoperability is included. A prompt string is stored but never executed.

The schema covers the experiment envelope. The runtime uses its own strict Python profile checks. Independent JSON Schema conformance and cross-language compatibility have not been established. Monitoring is manually supplied synthetic aggregate data checked against absolute operating limits, without a scheduler or alert delivery.

The framework does not define a universal human competence score, justify employee surveillance, or equate increased automation with progress. Local technical checks cannot establish human learning, quality, safety, organizational benefit, or suitability for a real deployment.

## Claims and versions

Draft-specified means a requirement is written. Implemented means code exists. Validated means a named check passed in a stated environment and scope. Adopted means a responsible decision was recorded. Activated means the chosen change was observed in its target. Beneficial means suitable outcome evidence supports that separate claim.

The document revision is v0.1; the experimental profile is `tsev-pilot/0.1`. Cite the repository source commit when reviewing this evolving draft. The [initial validation record](PILOT-VALIDATION-2026-10-02.md) identifies the tested source files by SHA-256. There is no external certification or full scoped conformance claim.

The companion TUN repositories were inspected as references and remain separate. New changes to those repositories do not automatically validate this draft. Source publication is distinct from a stable release, production deployment, or validated organizational adoption.
