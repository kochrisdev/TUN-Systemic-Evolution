Do not add infrastructure solely to match the conceptual record vocabulary. The next useful investment is a named adoption, followed by an adapter and actual evidence. Knowledge graphs, multi-agent optimization, training pipelines, dashboards, and autonomous experiment proposal should follow demonstrated needs.

Review the learning method itself after the first adoption: Which decisions changed? What mistakes stopped recurring? What did people learn? How much effort did the process cost? Remove fields and ceremonies that did not improve the decision.
